# გია გოგოლაშვილი — ვებგვერდი

ორენოვანი პორტფოლიო. ქართული მისამართები იწყება `/ka`-თი, ინგლისური — `/en`-ით. ენის გადამრთველი იმავე გვერდზე რჩება.

ტექსტი, პროექტები და ფოტოების აღწერა ცალკე ფაილებშია. გვერდის იერსახის შესაცვლელად კომპონენტების თავიდან წერა საჭირო არ არის.

## გაშვება

```bash
npm install
npm run dev
```

საიტი იხსნება ლოკალურ მისამართზე. გამოსაქვეყნებელი ვერსია:

```bash
npm run build
npm run preview
```

`photos/` საქაღალდეში ორიგინალი ფაილები უცვლელად რჩება. საიტი იყენებს მათგან მიღებულ მსუბუქ ასლებს `public/media/`-ში.

## რა სად იცვლება

| ამოცანა | ფაილი |
| --- | --- |
| მთავარი, ბიოგრაფია, მიდგომა, კონტაქტი | `content/pages.json` |
| ნამუშევრის ტექსტი, თარიღი, ადგილი | `content/projects.json` |
| მენიუ და ღილაკები | `content/ui.json` |
| ფოტოს აღწერა, alt და გამოქვეყნება | `content/images.json` |
| საჯარო მისამართი, სანამ დომენი გვექნება | `content/site.json` → `siteUrl` |

ტექსტის შენახვის შემდეგ გვერდები თავიდან იწერება `npm run content`-ით. თუ `npm run dev` უკვე გაშვებულია, `content/`-ის ცვლილებას საიტი თავად კითხულობს.

## ახალი ფოტო

1. ფაილი ჩაყარეთ `photos/`-ში ისე, როგორც არის. სახელი არ გადაარქვათ.
2. `content/images.json`-ში დაამატეთ ჩანაწერი: `id`, ზუსტი `filename`, `projectId`, `caption.ka`, `caption.en`, `alt.ka`, `alt.en`, `publish: true`.
3. პროექტის `images` სიაში ჩაწერეთ ეს `id`.
4. გაუშვით `npm run images` და `npm run content`.

Alt ტექსტი დაიწეროს კონკრეტული კადრის ნახვის შემდეგ. ცარიელი `filename` ან გამოგონილი მისამართი არ გამოიყენება. `publish: false` ნიშნავს, რომ ფაილი არქივშია და საიტზე არ ჩანს.

## ახალი პროექტი

`content/projects.json`-ში დაამატეთ ობიექტი სტაბილური `id`-ით, ქართული და ინგლისური სათაურით, აღწერით და ფოტოების `id`-ებით. გვერდი გაჩნდება `/ka/works/{id}/` და `/en/works/{id}/` მისამართებზე.

## რა არ არის საიტზე

ფოტოები გადავხედე და საიტზე მხოლოდ ნამუშევრები, ორი პორტრეტი, პიგმენტები და 2019 წლის სიგელი დავტოვე.

გამოქვეყნებული არ არის:

- პირადი და სოციალური კადრები, მათ შორის ამოუცნობი ადამიანებით
- ჟურნალ „სარკის“ გადაღებული გვერდები — სტატია ბმულითაა, ტექსტი არ არის გადმოტანილი
- მეტროპოლიტენის მუზეუმის გვერდის სურათი და წიგნის ყდა — ეს გია გოგოლაშვილის ნამუშევრები არ არის
- სტუდიის პორტრეტები, რომლის ფონზეც სხვისი ნამუშევრები ჩანს
- ვიდეოფაილები — არც ავტომატურად ირთვება და ჯერ საიტისთვის შერჩეული არ არის

ფოტოგრაფის სახელი არც ერთ კადრზე არ წერია, ამიტომ კრედიტი ცარიელია. სანამ ავტორი არ დადასტურდება, საიტი ფოტოგრაფს არ ასახელებს.

## სარედაქციო გადაწყვეტილებები

- 2022 წლის ინტერვიუ საკურთხევლის მოხატულობას 2018 წლით ასრულებს. სიგელი კი 2019 წლის 13 ოქტომბრით თარიღდება და ეხება მთავარანგელოზთა დასის შექმნასა და დამონტაჟებას. ორივე ფაქტი საიტზეა, ერთმანეთში არ არის არეული.
- „ამაღლება“ და „შობა“ ფოტოებით დასტურდება. მათი საბოლოო ადგილი და დასრულების თარიღი მასალებში არ წერია, ამიტომ ეს თარიღები საიტზეც არ არის. არც გელათის დაკარგული კომპოზიციის რესტავრაციად არის დასახელებული.
- „საიდუმლო სერობის“ კადრები დაბეჭდილი ფოტოს გადაღებაა. წარწერა ამას ამბობს.
- ტექნიკა buon fresco-დ არსად არის დასახელებული.
- გამოფენები და ჯილდოების ცალკე გვერდი არ არის. დადასტურებულია მხოლოდ 2019 წლის სიგელი.
- ასაკი და ურთიერთსაწინააღმდეგო ბიოგრაფიული თარიღები გამოტანილი არ არის.
- საკონტაქტო ფორმა გამორთულია. მისამართი და მიღების წესი ჯერ არ არის დადასტურებული, ამიტომ ფორმა წარმატებულ გაგზავნას არ აჩვენებს.

გამოქვეყნებამდე `content/site.json`-ში ჩაწერეთ რეალური `siteUrl`, რათა canonical, hreflang და sitemap სრული მისამართებით შეივსოს.
